# 网页版五子棋 (Gomoku)

基于 Node.js + WebSocket 的网页版五子棋，支持**本地双人、人机对战、在线实时对战**三种模式。

## 功能特性

- **本地双人**：同一设备上黑白双方轮流落子。
- **人机对战**：内置启发式评分 AI（攻防权衡，识别活四 / 冲四 / 活三 / 眠三等棋型），可一键切换先后手。
- **在线对战**：基于 WebSocket 的房间系统，创建房间并分享房间号，两人实时同步对弈；支持对手离开提示与重新开始同步。
- **棋盘交互**：Canvas 绘制 15×15 棋盘、星位、带高光的渐变棋子、最后一手标记、获胜连线高亮；响应式适配移动端。
- 支持**悔棋**与**重新开始**。

## 技术栈

- 后端：Node.js + Express（静态资源托管）+ `ws`（WebSocket 房间服务）
- 前端：原生 HTML / CSS / JavaScript（Canvas 渲染，无前端框架依赖）

## 目录结构

```
.
├── package.json        # 依赖与启动脚本
├── server.js           # Express 静态托管 + WebSocket 房间对战
└── public/
    ├── index.html      # 页面结构
    ├── style.css       # 样式
    ├── game.js         # 棋盘绘制 / 落子 / 胜负判定
    ├── ai.js           # 人机 AI（启发式评分）
    ├── online.js       # WebSocket 在线对战客户端
    └── main.js         # 主控制器（模式切换、事件协调）
```

## 运行方式

```bash
npm install
npm start          # 默认端口 3000
```

浏览器打开 `http://localhost:3000`。修改端口：

```bash
PORT=8080 npm start
```

## 使用说明

1. 顶部切换模式：**本地双人 / 人机对战 / 在线对战**。
2. **人机对战**：点击「你执黑(先手)」按钮可切换先后手，玩家落子后 AI 自动应招。
3. **在线对战**：
   - 一方点击「创建房间」，得到房间号；
   - 另一方在输入框填入房间号后点击「加入」；
   - 双方即可实时对弈，落子自动双向同步；黑棋先手。
4. 「悔棋」「重新开始」分别用于撤销上一步 / 重置棋盘（在线对战的重开始终与对手同步）。

## 胜负规则

任意方向（横、竖、两条斜线）连成五子即获胜；棋盘填满且无人连五为平局。
